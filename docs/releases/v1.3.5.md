# v1.3.5｜修复插件市场日志规范问题

- 移除插件自建文件日志器和轮转文件处理器，统一使用 `from astrbot.api import logger`，由 AstrBot 管理日志输出、持久化及轮转。
- 保留管理页脱敏日志缓存、筛选和 SSE 实时推送；日志级别设置仅控制本插件向宿主提交的输出，不修改宿主全局状态。
- 升级前旧日志文件保留且不再续写，存储页明确显示为“历史日志文件”；移除失效的独立文件日志总量设置，旧配置自动忽略。
- 新增 CI 日志规范检查和回归测试，防止非公共日志后端重新进入运行代码；同步版本、使用说明及安全文档。

验证：330 项测试通过，coverage.py 总覆盖率 84%；AstrBot 4.24.2、4.26.2、4.29.4 包级接口契约检查通过。

更新插件并重载即可，无数据库迁移，无新增运行依赖。管理页日志缓存会在重载后清空，历史运行日志请在 AstrBot 中查看。

本版针对已报告的日志规范问题完成代码修复；插件市场自动安全检查需重新提交验证，不将本地测试或 GitHub CI 通过描述为市场审核已通过。
