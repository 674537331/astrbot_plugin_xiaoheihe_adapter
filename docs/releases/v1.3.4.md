# v1.3.4｜修复小黑盒评论写签名，完善发送核对

## 修复

- 合入 @AmeiMiao 的 PR #32，补齐网页评论 `_rnd` 签名和写请求参数，修复评论发送返回“缺失参数”的问题。
- 签名在限流等待后生成，安全读取重试会刷新签名，避免排队或退避后继续使用旧签名。
- 发送结果核对增加帖子、根楼层、回复目标及时间校验，防止其他目标或较早的同文评论被误认成功；目标信息不足时保留“发送状态未知”，阻止自动重发。
- 写接口再次返回“缺失参数”时提供专门的契约排查提示。

- 同步版本、文档及维护审查，新增读写隔离、单次 POST 和错误发送核对回归测试。
